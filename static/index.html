What happens inside

1. Read the file

Filetape reads every byte and notes the name, all on your own device.

2. Shrink it

JPEGs go through the Truepix codec, and everything else through Deflate. If that doesn't help, the file is stored as it is.

3. Bytes become sound

Every two bytes of the winner become one 16-bit audio sample. Good compression looks random, so this sounds like loud white noise.

4. Press the tape

FLAC is the carrier, adding about 0.2%. Filetape decodes the result and compares every byte with your file before it hands you anything.

Measured, and every file came back exact

What shrinks, and by how much

Text, code and JPEGs shrink. Files that are already compressed, like PNGs, zips, MP3s and videos, don't shrink and grow by about 0.2%. Results depend on the file.

  • Text and code
    61–73% smaller
  • Programs
    61–64% smaller
  • JPEG photos
    20–23% smaller
  • One PDF
    About 10% smaller
  • One PNG
    0.2% larger
Batch

Whole folders fit on one tape

Zip a folder and drop it in. You get a new zip with the same folders, and uploading that zip turns everything back. Every file inside gets the same treatment, and anything that wouldn't shrink is copied unchanged.

In one test, a folder of 5 files went from 723 KB to 628 KB, and all 5 came back exactly, with the same names.

Your files never leave your device. Keep the audio in FLAC or WAV: MP3, AAC or re-recording it destroys the file.
