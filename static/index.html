Photophone

Turn an image into sound. Get every pixel back.

Photophone stores a picture as a FLAC audio file and can rebuild it exactly from that file. Most images come out smaller, and JPEGs come back byte for byte.

Drop an image, a Photophone audio file or a zip of a folder

PNG, JPEG, WebP, BMP, TIFF, GIF, FLAC or WAV, up to 40 MB and 50 megapixels. Zips up to 500 MB and 1,000 files.

Uploaded files are deleted from the server as soon as each conversion finishes. Keep the audio in FLAC or WAV: MP3, AAC or re-recording it destroys the image.
