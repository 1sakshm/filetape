Turn an image into sound. Get every pixel back.

What happens inside

1. Read every pixel

Photophone loads the image and keeps its colour profile, so the original can be rebuilt exactly.

2. Race the methods

It tries each method that applies: JPEG XL, prediction errors, or the file as it is. It checks each result and keeps the smallest.

3. Bytes become sound

Every two bytes of the winner become one 16-bit audio sample. Good compression looks random, so this sounds like loud white noise.

4. Press the tape

FLAC is the carrier, adding about 0.2%. Photophone decodes the result and compares it with your image before it hands you anything.

Measured on 23 sample images

All 23 came out smaller

Every image was restored exactly, and the total dropped by 30.8%. Results depend on the image, and a file that can't be compressed further grows by about 0.2%.

    27–59% smaller
  • Greyscale PNG
    6–45% smaller
  • JPEG
    13–22% smaller
Batch

Whole folders fit on one tape

Zip a folder and drop it in. You get a new zip with the same folders, and uploading that zip turns everything back. Files that wouldn't shrink are copied unchanged.

In one test, 10 files went from 27.2 MB to 18.8 MB, and all 10 came back with the same names.

Warning

One lossy step and the image is gone

Keep the audio in FLAC or WAV. MP3, AAC or re-recording it changes the samples, and the checksum refuses the file. Drag the slider to see why.
